# Aviso de privacidad de PACTO-T — borrador

Este repositorio contiene un **borrador para revisión**, no un aviso institucional aprobado. El repositorio está vacío y privado al iniciar este trabajo.

## Antes de usar o publicar

1. La institución responsable debe validar su identidad legal, domicilio, contacto de privacidad y fundamento jurídico.
2. El equipo técnico debe confirmar los datos que realmente recoge cada canal, dónde se alojan, quién puede consultarlos y cuánto tiempo se conservan.
3. La institución debe confirmar si es sujeto obligado o particular y revisar el régimen legal aplicable.
4. Sustituir todos los campos `[POR DEFINIR]` y retirar las instrucciones de borrador.
5. Obtener aprobación institucional documentada antes de habilitar GitHub Pages, cambiar la visibilidad del repositorio o configurar una URL de producción.

**No configures todavía este borrador como `PACTO_T_PRIVACY_NOTICE_URL` de producción.** Una página publicada con campos sin resolver no acredita un aviso institucional válido.

No se incluyen código de la aplicación, credenciales, tokens, secretos ni datos personales. No agregues esos elementos a este repositorio.

## Archivos

- `AVISO_PRIVACIDAD_BORRADOR.md`: texto de trabajo e instrucciones para la revisión.

## Fuentes normativas para revisión

La persona responsable de privacidad debe verificar la versión vigente y determinar cuál régimen aplica según la naturaleza jurídica del responsable:

- [Ley Federal de Protección de Datos Personales en Posesión de los Particulares — Cámara de Diputados](https://www.diputados.gob.mx/LeyesBiblio/pdf/LFPDPPP.pdf)
- [Decreto publicado en el Diario Oficial de la Federación el 20 de marzo de 2025](https://www.dof.gob.mx/nota_detalle.php?codigo=5752569&fecha=20/03/2025)

Este borrador no sustituye la revisión de la institución ni asesoría jurídica.
